Construction scans dense coordinates, keeps a dense snapshot, builds postings and caches document norms. Each query still computes its norm, creates all row scores and fully sorts them. Counts here describe dot-product structure, not elapsed time, memory, indexing amortization or semantic relevance.
The native PostingsRetriever is an immutable fixed-corpus snapshot of chunks, vectors and fitted IDF. Rebuild it after changing those inputs. Actual hashed-TF-IDF retrieval, extraction, citations and gates are checked separately against the unchanged original scan within each supported Python runtime. This browser uses an independent dense row-first reference on bounded integer vectors, not a second copy of the native postings traversal.
Signed hashing can collide, cancel and produce misleading similarities. Exact retrieval in that hashed space does not repair those representations. Lexical grounding remains lexical overlap, not entailment, factuality or source authentication. The controls are synthetic engineering checks.
